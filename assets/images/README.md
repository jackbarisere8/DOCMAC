Place the DOCMAC logo image here as a PNG named:

  assets/images/docmac_logo.png

Recommendations:
- Use a transparent PNG (preferred) so the logo works on dark/light backgrounds.
- Size: 512×512 or 1024×1024 for high resolution; the app will scale it down (120px used in splash).
- Optimize for web/mobile (pngcrush/oxipng recommended).

After adding the file run:

```bash
flutter pub get
```

Then run the app.
